# 編集用の元データ

- `q.txt`：問題。`#コード|単元名` の行のあとに `問題|答え|選択肢` を並べる。コードの頭文字でコーナーが決まる（数字＝地理、J＝時事、N＝年表、H＝歴史、C＝公民）。
- `tpl.html`：画面とプログラム。
- `build.py` / `mkapp.py`：`q.txt` を検査して公開用ファイルを作る。`sh src/make.sh` でまとめて実行する。

## 記録を消さないための決まり

端末内の記録は「単元の番号-問題の番号」で保存している。
- 新しい問題は、単元の**末尾**に足す（途中に入れない、並べ替えない、消さない）。
- 新しい単元は、ファイルの**末尾**に足す。
- 問題文の誤りは、その行を書き直すだけにする。
